# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    |  Yes    |
| > 0.1.0 |  No     |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Report privately to: **jdtp717@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive acknowledgement within **72 hours**. We follow **responsible disclosure**  fixes will be coordinated before public disclosure.

## Scope

- Governance logic bypasses
- Safety invariant violations
- Authentication or authorization flaws
- Data integrity issues

## Out of Scope

- Issues in third-party dependencies
- Social engineering attacks
